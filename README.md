# Worterratespiel
Konsolenbasiertes Worterratespiel in Java aus dem 2. Semester
(Wirtschaftsinformatik, Hochschule Osnabrück).

Funktionen: Anmeldung mit Benutzername und Passwort, zufälliges Wort
aus einer Textdatei, Glücksrad mit Punkten, Highscore pro Benutzer,
Speichern und Laden der Benutzer über Textdateien.

Hinweis: Studienprojekt, die Passwörter werden bewusst einfach
im Klartext gespeichert.

Starten über die Klasse Main. Die Dateien benutzer.txt und
woerter.txt müssen im selben Ordner liegen.
